1. Resumen del Proyecto

1.1 Descripción del Sistema

El Cronograma de Licencia Anual es una aplicación web desarrollada para ETAC - Guardia A, BASE PUNILLA, diseñada para gestionar y organizar las licencias anuales del personal de manera eficiente y transparente.

La aplicación permite registrar efectivos, asignar franjas de licencia, visualizar un calendario interactivo con la distribución de licencias, y generar reportes exportables para respaldo físico o digital.

1.2 Objetivos del Sistema

  • Centralizar la información de licencias del personal en el navegador.
  • Permitir que múltiples usuarios vean y modifiquen los datos.
  • Visualizar de forma clara la distribución de licencias en un calendario interactivo.
  • Controlar el cupo máximo de personas simultáneas en licencia (máximo 3).
  • Generar reportes imprimibles y exportables para respaldo administrativo.
  • Llevar un control de días disponibles, usados y restantes por efectivo.
  • Implementar un sistema de seguridad con login y gestión de usuarios.

1.3 Características Principales

  • Registro de efectivos con datos personales y días disponibles.
  • Asignación de hasta dos franjas de licencia por efectivo.
  • Calendario interactivo con tooltips informativos.
  • Detección visual de días que superan el cupo máximo.
  • Edición y eliminación de registros existentes.
  • Exportación de datos en formato CSV.
  • Importación de datos desde CSV.
  • Impresión de listados para respaldo físico.
  • Sistema de autenticación con usuarios y contraseñas.
  • Recuperación de contraseña mediante código de seguridad.
  • Cierre de sesión manual y automático por inactividad.
  • Almacenamiento en el navegador mediante localStorage.

4. Instalación y Configuración

4.1 Requisitos del Sistema

  • Navegador web: Google Chrome, Microsoft Edge, Mozilla Firefox o Safari (cualquier versión moderna).
  • Sistema operativo: Windows, macOS, Linux o cualquier sistema con navegador.
  • Conexión a internet: No necesaria para usar la aplicación.

4.2 Instalación

1Descargar la carpeta ETAC - Cronograma de vacaciones desde el medio de almacenamiento compartido (USB, OneDrive, Google Drive, etc.).

2Si la carpeta está comprimida (.zip), descomprimirla en el escritorio o en la carpeta de documentos.

3Verificar que estén los archivos: index.html, styles.css y app.js.

4Hacer doble clic en index.html para abrir la aplicación en el navegador predeterminado.

4.3 Configuración del Navegador

La aplicación funciona en cualquier navegador moderno. Se recomienda usar Microsoft Edge o Google Chrome para mejor compatibilidad.

Nota: Si al abrir la aplicación no carga correctamente, presionar Ctrl + F5 para forzar la recarga completa de la página.

5. Guía de Uso

5.1 Iniciar Sesión

1Abrir la aplicación haciendo doble clic en index.html.

2Aparece la pantalla de login con el logo ETAC.

3Ingresar usuario y contraseña.

4Hacer clic en "Ingresar" o presionar Enter.

5Si los datos son correctos, se muestra la aplicación.

5.2 Registrar un Efectivo

1En el formulario, completar los campos:

  • Apellido y Nombre: Formato "Apellido, Nombre" (ej: García, Juan).
  • DNI: Número de documento sin puntos ni espacios.
  • Días hábiles disponibles: Total de días de licencia que le corresponden al efectivo.

2En Primera franja, seleccionar la fecha de inicio y la cantidad de días hábiles.

3En Segunda franja (opcional), seleccionar la fecha de inicio y la cantidad de días hábiles.

4Verificar que el calendario muestre los días asignados correctamente.

5Hacer clic en "Añadir efectivo".

6El efectivo aparecerá en la lista de "Efectivos registrados".

5.3 Editar un Efectivo

1En la lista de efectivos, hacer clic en el botón "Editar" del efectivo que se desea modificar.

2Los datos del efectivo se cargarán automáticamente en el formulario.

3Modificar los campos necesarios.

4Hacer clic en "Guardar cambios".

5Para cancelar la edición, hacer clic en "Cancelar edición".

5.4 Eliminar un Efectivo

1En la lista de efectivos, hacer clic en el botón "Eliminar" del efectivo que se desea quitar.

2Aparece un cartel de confirmación: "¿Estás seguro de que querés eliminar a [Nombre]? Esta acción no se puede deshacer."

3Si se acepta, el efectivo se eliminará automáticamente.

Advertencia: La eliminación es permanente. No se puede deshacer.

5.5 Usar el Calendario

El calendario muestra la distribución de licencias con los siguientes colores:

Color Significado
■ Azul Día de primera franja
■ Verde Día de segunda franja
■ Rojo oscuro Día ocupado (1-3 personas)
■ Rojo brillante Día prohibido (más de 3 personas)
■ Marrón Día feriado
■ Gris Día libre

Navegación del calendario

  • Usar los botones "← Anterior" y "Siguiente →" para cambiar de mes.
  • Pasar el cursor sobre un día para ver información detallada (tooltip).
  • En dispositivos táctiles, tocar un día para ver la información.

5.6 Ver Listado Completo

1Hacer clic en el botón "Ver listado" (arriba a la derecha de la lista de efectivos).

2Se abre una ventana con una tabla que muestra todos los efectivos ordenados alfabéticamente.

3La tabla incluye: Apellido y Nombre, Días disponibles, Días usados, Días restantes, 1ª Franja y 2ª Franja.

5.7 Exportar a CSV

1Abrir el listado completo (botón "Ver listado").

2Hacer clic en "Exportar CSV".

3Se descarga un archivo llamado listado_efectivos_etac.csv.

4Abrir el archivo con Excel, Google Sheets o cualquier programa de hojas de cálculo.

5.8 Importar CSV

1Abrir el listado completo (botón "Ver listado").

2Hacer clic en "Importar CSV".

3Seleccionar el archivo CSV a importar.

4Los datos se cargan automáticamente a la aplicación.

Formato del CSV: El archivo debe tener las columnas: Apellido y Nombre, Días disponibles, Días usados, Días restantes, 1ª Franja (Inicio - Fin), 2ª Franja (Inicio - Fin).

5.9 Imprimir el Listado

1Abrir el listado completo (botón "Ver listado").

2Hacer clic en "Imprimir".

3Se abre el diálogo de impresión del navegador.

4Seleccionar la impresora y hacer clic en "Imprimir".

5.10 Cerrar Sesión

1Hacer clic en el botón "Cerrar Sesión" en el encabezado.

2La aplicación vuelve a la pantalla de login.

6. Sistema de Seguridad

6.1 Pantalla de Login

Al abrir la aplicación, aparece una pantalla de login con:

  • Campo Usuario
  • Campo Contraseña
  • Botón "Ingresar"
  • Enlace "Olvidé mi contraseña"

6.2 Verificación de Credenciales

El sistema verifica:

  • Que el usuario exista en el sistema.
  • Que la contraseña sea correcta.
  • Que el usuario esté activo (no desactivado).

Si alguna verificación falla, se muestra un mensaje de error.

6.3 Recuperación de Contraseña

1Hacer clic en "Olvidé mi contraseña".

2Ingresar el código de recuperación: ETAC-2026.

3Ingresar el nombre de usuario.

4Crear una nueva contraseña.

Importante: La nueva contraseña es temporal. Para hacerla permanente, se debe editar el array USUARIOS en el código.

6.4 Auto-cierre por Inactividad

Después de 20 minutos sin usar la aplicación, la sesión se cierra automáticamente.

Si el usuario está usando la aplicación (moviendo el mouse, escribiendo, etc.), el temporizador se reinicia.

7.2 Agregar un Nuevo Usuario

  1. Abrir el archivo index.html con el Bloc de notas.
  2. Buscar la sección SISTEMA DE USUARIOS.
  3. Copiar la línea de un usuario existente.
  4. Modificar el nombre de usuario y la contraseña.
  5. Guardar el archivo.
// Ejemplo: agregar un usuario nuevo
{ usuario: 'nombrenuevo', clave: 'clave123', activo: true, rol: 'usuario' },

7.3 Desactivar un Usuario

  1. Abrir el archivo index.html con el Bloc de notas.
  2. Buscar el usuario en la sección SISTEMA DE USUARIOS.
  3. Cambiar activo: true por activo: false.
  4. Guardar el archivo.

7.4 Cambiar la Contraseña de un Usuario

  1. Abrir el archivo index.html con el Bloc de notas.
  2. Buscar el usuario en la sección SISTEMA DE USUARIOS.
  3. Modificar el valor de clave.
  4. Guardar el archivo.

7.5 Cambiar el Código de Recuperación

  1. Abrir el archivo index.html con el Bloc de notas.
  2. Buscar la constante CLAVE_RECUPERACION.
  3. Modificar el valor por el código deseado.
  4. Guardar el archivo.

Quiero crear desde cero "ETAC - Cronograma de Licencia Anual", una web para registrar las licencias anuales de un grupo de personas y organizarlo ordenadamente. La aplicación es para ETAC - Guardia A, BASE PUNILLA. Diseñado por: Maldonado Jorge Matias.
