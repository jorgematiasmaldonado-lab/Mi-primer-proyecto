1. Introducción

1.1 Descripción del Sistema

El Cronograma de Licencia Anual es una aplicación web desarrollada para ETAC - Guardia A, BASE PUNILLA, diseñada para gestionar y organizar las licencias anuales del personal de manera eficiente y transparente.

La aplicación permite registrar efectivos, asignar franjas de licencia, visualizar un calendario interactivo con la distribución de licencias, y generar reportes exportables para respaldo físico o digital.

1.2 Objetivos del Sistema

  • Centralizar la información de licencias del personal en el navegador.
  • Permitir que múltiples usuarios vean y modifiquen los datos.
  • Visualizar de forma clara la distribución de licencias en un calendario interactivo.
  • Controlar el cupo máximo de personas simultáneas en licencia (máximo 3).
  • Generar reportes imprimibles y exportables para respaldo administrativo.
  • Llevar un control de días disponibles, usados y restantes por efectivo.

1.3 Características Principales

  • Registro de efectivos con datos personales y días disponibles.
  • Asignación de hasta dos franjas de licencia por efectivo.
  • Calendario interactivo con tooltips informativos.
  • Detección visual de días que superan el cupo máximo.
  • Edición y eliminación de registros existentes.
  • Exportación de datos en formato CSV.
  • Impresión de listados para respaldo físico.
  • Almacenamiento en el navegador mediante localStorage.

2. Requisitos del Sistema

2.1 Requisitos de Hardware

  • Computadora con conexión a internet (opcional, solo para cargar la app).
  • Procesador: Cualquiera moderno (no requiere recursos especiales).
  • Memoria RAM: Mínimo 2 GB recomendado.
  • Espacio en disco: Menos de 1 MB (los archivos son muy pequeños).

2.2 Requisitos de Software

  • Navegador web: Google Chrome, Microsoft Edge, Mozilla Firefox o Safari (cualquier versión moderna).
  • Sistema operativo: Windows, macOS, Linux o cualquier sistema con navegador.

2.3 Archivos del Sistema

Archivo Descripción Tamaño aproximado
index.html Estructura principal de la aplicación (interfaz de usuario). ~15 KB
styles.css Estilos y diseño visual de la aplicación. ~15 KB
app.js Lógica de la aplicación y conexión con localStorage. ~25 KB
Importante: Los tres archivos deben estar siempre en la misma carpeta. Si falta alguno, la aplicación no funcionará correctamente.

3. Instalación y Configuración

3.1 Instalación Inicial

1Descargar la carpeta ETAC - Cronograma de vacaciones desde el medio de almacenamiento compartido (USB, OneDrive, Google Drive, etc.).

2Si la carpeta está comprimida (.zip), descomprimirla en el escritorio o en la carpeta de documentos.

3Verificar que los tres archivos estén presentes: index.html, styles.css y app.js.

4Hacer doble clic en index.html para abrir la aplicación en el navegador predeterminado.

3.2 Configuración del Navegador

La aplicación funciona en cualquier navegador moderno. Se recomienda usar Microsoft Edge o Google Chrome para mejor compatibilidad.

Nota: Si al abrir la aplicación no carga correctamente, presionar Ctrl + F5 para forzar la recarga completa de la página.

4. Guía de Uso

4.1 Registrar un Efectivo

1Abrir la aplicación haciendo doble clic en index.html.

2En el formulario, completar los campos:

  • Apellido y Nombre: Formato "Apellido, Nombre" (ej: García, Juan).
  • DNI: Número de documento sin puntos ni espacios.
  • Días hábiles disponibles: Total de días de licencia que le corresponden al efectivo.

3En Primera franja, seleccionar la fecha de inicio y la cantidad de días hábiles.

4En Segunda franja (opcional), seleccionar la fecha de inicio y la cantidad de días hábiles.

5Verificar que el calendario muestre los días asignados correctamente.

6Hacer clic en "Añadir efectivo".

7El efectivo aparecerá en la lista de "Efectivos registrados".

4.2 Editar un Efectivo

1En la lista de efectivos, hacer clic en el botón "Editar" del efectivo que se desea modificar.

2Los datos del efectivo se cargarán automáticamente en el formulario.

3Modificar los campos necesarios.

4Hacer clic en "Guardar cambios".

5Para cancelar la edición, hacer clic en "Cancelar edición".

4.3 Eliminar un Efectivo

1En la lista de efectivos, hacer clic en el botón "Eliminar" del efectivo que se desea quitar.

2El efectivo se eliminará automáticamente de la base de datos.

Advertencia: La eliminación es permanente. No se puede deshacer.

4.4 Ver Detalles de un Efectivo

1En la lista de efectivos, hacer clic en el botón "Detalles".

2Se desplegará un panel con la información completa:

  • Primera franja: inicio, fin y días hábiles.
  • Segunda franja: inicio, fin y días hábiles.
  • Resumen: días disponibles, usados y restantes.

3Hacer clic en "Detalles" de nuevo para cerrar el panel.

4.5 Usar el Calendario

El calendario muestra la distribución de licencias con los siguientes colores:

Color Significado
■ Azul Día de primera franja
■ Verde Día de segunda franja
■ Rojo oscuro Día ocupado (1-3 personas)
■ Rojo brillante Día prohibido (más de 3 personas)
■ Marrón Día feriado
■ Gris Día libre

Navegación del calendario

  • Usar los botones "← Anterior" y "Siguiente →" para cambiar de mes.
  • Pasar el cursor sobre un día para ver información detallada (tooltip).
  • En dispositivos táctiles, tocar un día para ver la información.

4.6 Ver Listado Completo

1Hacer clic en el botón "Ver listado" (arriba a la derecha de la lista de efectivos).

2Se abrirá una ventana con una tabla que muestra todos los efectivos ordenados alfabéticamente.

3La tabla incluye las columnas: Apellido y Nombre, Días disponibles, Días usados, Días restantes, 1ª Franja y 2ª Franja.

4.7 Exportar a CSV

1Abrir el listado completo (botón "Ver listado").

2Hacer clic en "Exportar CSV".

3Se descargará un archivo llamado listado_efectivos_etac.csv.

4Abrir el archivo con Excel, Google Sheets o cualquier programa de hojas de cálculo.

4.8 Imprimir el Listado

1Abrir el listado completo (botón "Ver listado").

2Hacer clic en "Imprimir".

3Se abrirá el diálogo de impresión del navegador.

4Seleccionar la impresora y hacer clic en "Imprimir".

Nota: El listado se imprime en formato optimizado para papel, con fondo blanco y sin colores oscuros.

6. Reglas de Validación

6.1 Período de Licencias

Las licencias solo pueden asignarse entre el 01/12/2026 y el 30/06/2027.

6.2 Cupo Máximo

Máximo 3 personas en licencia simultáneamente. Si un día supera este límite, se marca como "Prohibido" en color rojo brillante.

6.3 Días Disponibles

Cada efectivo tiene un límite de días disponibles. No se pueden asignar más días de los que el efectivo tiene disponibles.

6.4 Días Hábiles

Se cuentan solo días hábiles (lunes a viernes), excluyendo sábados, domingos y feriados.

6.5 Mensajes de Error

Error Causa Solución
"El apellido y nombre son obligatorios" No se completó el campo nombre Completar el campo
"El DNI es obligatorio" No se completó el campo DNI Completar el campo
"Los días hábiles disponibles son obligatorios" No se completó el campo de días disponibles Completar el campo
"La fecha de inicio no puede ser posterior a la de finalización" La fecha de inicio es mayor que la de fin Corregir las fechas
"Las fechas deben estar entre el 01/12/2026 y el 30/06/2027" La fecha está fuera del período permitido Usar una fecha dentro del rango
"No podés tomar más días de los que tenés disponibles" La suma de días de ambas franjas supera los días disponibles Reducir los días o aumentar los disponibles

7. Compartir la Aplicación

7.1 Métodos de Compartición

Opción 1: USB

  1. Copiar la carpeta completa a una memoria USB.
  2. Conectar la USB en la otra computadora.
  3. Copiar la carpeta al escritorio o documentos.
  4. Abrir index.html con doble clic.

Opción 2: OneDrive / Google Drive

  1. Subir la carpeta completa a OneDrive o Google Drive.
  2. Compartir el enlace con los usuarios.
  3. Cada usuario descarga la carpeta.
  4. Descomprimir y abrir index.html.
Importante: No abrir index.html directamente desde Google Drive. Primero descargar la carpeta completa.

Opción 3: Red Interna

  1. Colocar la carpeta en una ubicación de red compartida.
  2. Los usuarios acceden a la carpeta desde la red.
  3. Abrir index.html desde la ubicación de red.

7.2 Consideraciones de Seguridad

  • La aplicación no requiere conexión a internet para funcionar.
  • Los datos se almacenan en el navegador (localStorage).
  • Cualquier persona con acceso a los archivos puede usar la aplicación.
  • Solo el administrador puede modificar el código fuente.

8. Solución de Problemas

8.1 Problemas Comunes

La aplicación no carga

  • Verificar que los tres archivos estén en la misma carpeta.
  • Presionar Ctrl + F5 para recargar la página.
  • Probar con otro navegador (Edge o Chrome).

Los datos no se guardan

  • Verificar que el navegador permita localStorage.
  • Verificar que no se esté en modo incógnito.
  • Revisar la consola del navegador (F12) para ver errores.

El calendario no muestra los días

  • Verificar que las fechas estén dentro del período permitido.
  • Verificar que los días hábiles sean mayores a 0.
  • Recargar la página.

No se puede abrir desde Google Drive

  • Descargar la carpeta completa primero.
  • Descomprimir y abrir desde la computadora.

9. Mantenimiento

9.1 Agregar Feriados Nuevos

Para agregar un feriado nuevo, editar el archivo app.js y agregar una línea en el objeto FERIADOS:

const FERIADOS = {
    '2026-12-08': 'Inmaculada Concepción',
    '2026-12-24': 'Noche Buena',
    // ... otros feriados ...
    '2027-07-09': 'Día de la Independencia',  // Nuevo feriado
};

Formato: 'AAAA-MM-DD': 'Nombre del feriado'

9.2 Modificar el Período de Licencias

Para cambiar las fechas límite, editar las constantes al inicio de app.js:

const FECHA_MINIMA = '2026-12-01';
const FECHA_MAXIMA = '2027-06-30';

9.3 Modificar el Cupo Máximo

Para cambiar el máximo de personas simultáneas, editar la constante:

const MAX_SIMULTANEAS = 3;

9.4 Copia de Seguridad de los Datos

Para hacer una copia de seguridad:

  1. Abrir la aplicación.
  2. Hacer clic en "Ver listado".
  3. Hacer clic en "Exportar CSV".
  4. Guardar el archivo CSV en un lugar seguro.

function formatearFechaLocal(fecha) {
    const año = fecha.getFullYear();
    const mes = String(fecha.getMonth() + 1).padStart(2, '0');
    const dia = String(fecha.getDate()).padStart(2, '0');
    return año + '-' + mes + '-' + dia;
}

function esDiaNoHabil(fechaStr) {
    const fecha = new Date(fechaStr + 'T00:00:00');
    const diaSemana = fecha.getDay();
    return diaSemana === 0 || diaSemana === 6 || FERIADOS.hasOwnProperty(fechaStr);
}

function obtenerDiasHabiles(fechaInicio, fechaFin) {
    const dias = [];
    let actual = new Date(fechaInicio + 'T00:00:00');
    const fin = new Date(fechaFin + 'T00:00:00');

    while (actual <= fin) {
        const fechaStr = formatearFechaLocal(actual);
        if (!esDiaNoHabil(fechaStr)) {
            dias.push(fechaStr);
        }
        actual.setDate(actual.getDate() + 1);
    }

    return dias;
}

function obtenerPrimerosDiasHabiles(fechaInicio, cantidad) {
    const dias = [];
    let actual = new Date(fechaInicio + 'T00:00:00');
    let contador = 0;

    while (contador < cantidad) {
        const fechaStr = formatearFechaLocal(actual);
        if (!esDiaNoHabil(fechaStr)) {
            dias.push(fechaStr);
            contador++;
        }
        actual.setDate(actual.getDate() + 1);
    }

    return dias;
}

function contarEnDia(fechaStr, efectivos) {
    let count = 0;
    for (let i = 0; i < efectivos.length; i++) {
        if (efectivos[i].dias.indexOf(fechaStr) !== -1) {
            count++;
        }
    }
    return count;
}

function obtenerApellidosEnDia(fechaStr, efectivos) {
    const apellidos = [];
    for (let i = 0; i < efectivos.length; i++) {
        if (efectivos[i].dias.indexOf(fechaStr) !== -1) {
            const nombre = efectivos[i].nombre;
            const partes = nombre.split(',');
            apellidos.push(partes[0].trim());
        }
    }
    return apellidos;
}

function obtenerEfectivosEnDia(fechaStr, efectivos) {

function obtenerDiasDelMes(año, mes) {
    const primerDia = new Date(año, mes, 1);
    const ultimoDia = new Date(año, mes + 1, 0);
    const diasEnMes = ultimoDia.getDate();
    const diaSemanaInicio = primerDia.getDay();

    const dias = [];

    for (let i = 0; i < diaSemanaInicio; i++) {
        dias.push(null);
    }

    for (let d = 1; d <= diasEnMes; d++) {

function mostrarTooltip(event) {
    const fechaStr = event.currentTarget.dataset.fecha;
    const efectivos = cargarEfectivos();
    const tooltip = document.getElementById('tooltip');

    const personas = obtenerEfectivosEnDia(fechaStr, efectivos);
    const esFeriado = FERIADOS.hasOwnProperty(fechaStr);
    const cantidadEnDia = contarEnDia(fechaStr, efectivos);
    const esProhibido = cantidadEnDia > MAX_SIMULTANEAS;

    let html = '
' + formatearFechaLegible(fechaStr) + '
';

    // Mostrar nombre del feriado si es un día feriado
    if (esFeriado) {
        html += '
' + FERIADOS[fechaStr] + '
';
    }

    // Mostrar advertencia si supera el cupo
    if (esProhibido) {
        html += '
Supera el cupo (' + cantidadEnDia + ' personas)
';
    }

    if (personas.length === 0) {
        html += '
Sin licencia
';
    } else {
        for (let i = 0; i < personas.length; i++) {
            html += '
' + personas[i].nombre + '
' + personas[i].franja + '
';
        }
    }

    tooltip.innerHTML = html;
    tooltip.classList.add('visible');

    const rect = event.currentTarget.getBoundingClientRect();
    const tooltipRect = tooltip.getBoundingClientRect();

    let left = rect.left + rect.width / 2 - tooltipRect.width / 2;
    let top = rect.top - tooltipRect.height - 8;

    if (left < 8) left = 8;
    if (left + tooltipRect.width > window.innerWidth - 8) {
        left = window.innerWidth - tooltipRect.width - 8;
    }
    if (top < 8) top = rect.bottom + 8;

    tooltip.style.left = left + 'px';
    tooltip.style.top = top + 'px';
}

function validarFormulario(nombre, dni, diasDisponibles, fechaInicio, diasF1, fechaInicioF2, diasF2) {
    if (!nombre.trim()) {
        return 'El apellido y nombre son obligatorios.';
    }

    if (!dni.trim()) {
        return 'El DNI es obligatorio.';
    }

    if (!diasDisponibles || diasDisponibles < 1) {
        return 'Los días hábiles disponibles son obligatorios y deben ser al menos 1.';
    }

    if (!fechaInicio) {
        return 'La fecha de inicio de la primera franja es obligatoria.';
    }

    if (fechaInicio < FECHA_MINIMA || fechaInicio > FECHA_MAXIMA) {
        return 'Las fechas deben estar entre el 01/12/2026 y el 30/06/2027.';
    }

    if (diasF1 < 0) {
        return 'Los días de la primera franja no pueden ser negativos.';
    }

    if (fechaInicioF2 || diasF2 > 0) {
        if (!fechaInicioF2) {
            return 'Si completás días de la segunda franja, también necesitás la fecha de inicio.';
        }
        if (diasF2 <= 0) {
            return 'Si completás la fecha de la segunda franja, también necesitás los días hábiles.';
        }
        if (fechaInicioF2 < FECHA_MINIMA || fechaInicioF2 > FECHA_MAXIMA) {
            return 'Las fechas deben estar entre el 01/12/2026 y el 30/06/2027.';
        }
    }

    // Calcular días hábiles totales
    const calculado = calcularFranjas(fechaInicio, diasF1, fechaInicioF2, diasF2);
    const totalDias = calculado.franja1.length + calculado.franja2.length;

    // Validar que no se excedan los días disponibles
    if (totalDias > diasDisponibles) {
        return 'No podés tomar más días de los que tenés disponibles. Tenés ' + diasDisponibles + ' días y querés tomar ' + totalDias + '.';
    }

    return null;
}

function agregarEfectivo(nombre, dni, diasDisponibles, fechaInicio, diasF1, fechaInicioF2, diasF2) {
    const efectivos = cargarEfectivos();
    const calculado = calcularFranjas(fechaInicio, diasF1, fechaInicioF2, diasF2);

    const todosDias = calculado.franja1.concat(calculado.franja2);
    todosDias.sort();

    const nuevo = {
        id: Date.now(),
        nombre: nombre.trim(),
        dni: dni.trim(),
        diasDisponibles: diasDisponibles,
        fechaInicio: fechaInicio,
        dias: todosDias,
        franja1: calculado.franja1,
        franja2: calculado.franja2,
    };

    efectivos.push(nuevo);
    guardarEfectivos(efectivos);
}

function actualizarEfectivo(id, nombre, dni, diasDisponibles, fechaInicio, diasF1, fechaInicioF2, diasF2) {
    const efectivos = cargarEfectivos();
    let index = -1;

    for (let i = 0; i < efectivos.length; i++) {
        if (efectivos[i].id === id) {
            index = i;
            break;
        }
    }

    if (index === -1) return;

    const calculado = calcularFranjas(fechaInicio, diasF1, fechaInicioF2, diasF2);

    const todosDias = calculado.franja1.concat(calculado.franja2);
    todosDias.sort();

    efectivos[index].nombre = nombre.trim();
    efectivos[index].dni = dni.trim();
    efectivos[index].diasDisponibles = diasDisponibles;
    efectivos[index].fechaInicio = fechaInicio;
    efectivos[index].dias = todosDias;
    efectivos[index].franja1 = calculado.franja1;
    efectivos[index].franja2 = calculado.franja2;

    guardarEfectivos(efectivos);
}

function eliminarEfectivo(id) {
    const efectivos = cargarEfectivos();
    const nuevos = [];

    for (let i = 0; i < efectivos.length; i++) {
        if (efectivos[i].id !== id) {
            nuevos.push(efectivos[i]);
        }
    }

    guardarEfectivos(nuevos);
}
